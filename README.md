# Демо динамической главной Skillaz

Локальная адаптивная страница по макетам динамического виджета.

Онлайн-версия: <https://yulia405.github.io/skillaz-dynamic-home/>

На странице оставлены только:

- приветствие;
- динамический виджет;
- новости.

Блоки «Продолжить обучение», «Мои задачи», «Календарь» и «Моё обучение» не добавлены ни в desktop, ни в mobile.

## Запуск

```powershell
.\serve.ps1
```

Открыть: <http://127.0.0.1:8090>

## Интерактивность

- переключение вопросных табов;
- раскрытие и сворачивание карточек через «Показать все»;
- мобильное меню;
- демо-реакции на действия карточек, настройки и новости.
